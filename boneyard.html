Boneyard

Org-wide tech-debt radar. Discovers and ranks internal repositories by dormancy, exposure, dependency depth, and AI-agent attack surface to emit actionable remediation budgets.

View on GitHub → Framework Doctrine →

01

What it does

Five-Axis Repo Scoring

Evaluates repos across dormancy, risk, exposure, dependency depth, and AI-agent surface.

Composite Boneyard Index

Computes an org-wide health score in [0, 100] categorized into unambiguous Red, Amber, and Green risk tiers.

Remediation Budgets

Quantifies tech debt into concrete engineering work units, generating estimates in repo-weeks for sprint planning.

TOML Policy Gate

Enforces org-wide security and maintenance policies in CI, preventing unreviewed orphan repos from going public.

02

GitHub Actions & CI Enforcement

Audit repository debt catalogs on pull requests and scheduled cron runs using the Boneyard action.

# Prompt for your AI Agent (Cursor, Claude Code, Copilot, Devin):
Add a GitHub Actions workflow at .github/workflows/boneyard.yml using studio2201/boneyard@master. Run on pull requests and a weekly schedule, evaluate repository catalogs against technical debt policies, calculate remediation budgets, and fail if the Boneyard Index exceeds allowed limits.
# .github/workflows/boneyard.yml
name: Boneyard Tech-Debt Radar
on:
  schedule:
    - cron: '0 0 * * 1'
  pull_request:
    branches: [ master, main ]
jobs:
  boneyard-audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Audit Repository Debt
        uses: studio2201/boneyard@master
        with:
          input: 'catalog.json'
# Workstation CLI installation (unprivileged, installs to ~/.local/bin):
curl -fsSL https://studio2201.com/install.sh | sh -s boneyard

03

Terminal usage

# Ingest org repositories and score dormancy
boneyard enrich --input repos.json --output scored.json

# Generate executive markdown report with remediation budgets
boneyard report --input scored.json --policy policy.toml --output report.md

# Assert compliance against org policy in CI
boneyard policy check --input scored.json --policy policy.toml

05

How It Works Under the Hood

Catalog Ingestion

Parses multi-repository catalog dumps in JSON or NDJSON format with zero external crates.

Five-Axis Scoring Engine

Calculates weighted dormancy, risk, exposure, depth, and AI-generated surface into a composite [0, 100] index.

Repo-Week Budgeting

Models human remediation capacity based on codebase volume, dependency branching, and age of last commit.

TOML Policy Enforcement

Asserts deterministic exit code 1 when any repo exceeds maximum allowed debt index in CI pull requests.
