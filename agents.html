01 · HEADLESS & MACHINE CLI

Strict CLI contract & tri-state exit codes.

All five tools implement a deterministic headless interface for programmatic integration into agent toolkits and background watchers.

Flags

Standard Flags

--format json emits machine schemas; -q silences stdout; -v logs diagnostics to stderr; -o <FILE> writes output directly to disk.

Exit Contract

Tri-State Exit Codes

0 = Clean verdict (ship); 1 = Security findings (BLOCK/FIX); 2 = Argument parse error or runtime I/O failure.

git diff --staged | snip audit --format json
git diff --staged | snip audit -q || echo "Security violation detected"

Model Context Protocol (MCP) & agent directives.

// claude_desktop_config.json or ~/.cursor/mcp.json

# studio2201 Autonomous Security Rules (.cursorrules / CLAUDE.md)
- Audit diffs with 'snip', manifests with 'vigil', and crypto call sites with 'aegis' via GitHub Actions or local binaries.
- If Snip emits exit code 1 (Block/Fix): remediate leaked secrets, broken RLS, or permissive CORS.
- If Vigil emits exit code 1: reject dormant packages (>365d) in package.json, Cargo.lock, requirements.txt, or go.mod.
- If Aegis emits exit code 1: upgrade classical cryptography to NIST PQC standards (ML-KEM, ML-DSA).

03 · CI/CD PIPELINES

Standalone pull-request gates.

Gate code modifications continuously in pull request workflows using independent studio2201/<tool>@v1 actions.

# Reference template: .github/workflows/<tool>.yml (snip, vigil, aegis, proven, boneyard)
name: snip
on:
  push: { branches: [ master, main ] }
  pull_request: { branches: [ master, main ] }
  workflow_dispatch:
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}
permissions: { contents: read }
jobs:
  snip:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
        with: { fetch-depth: 0 }
      - uses: studio2201/snip@v1
      - uses: actions/upload-artifact@v6
        if: always()
        with: { name: snip-report, path: snip_summary.md, if-no-files-found: ignore }
