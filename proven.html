01 · CAPABILITIES

What it does for release provenance.

Signatures

RFC 2104 HMAC-SHA256

Signs canonical sha256:merkleRoot:keyId payloads using constant-time pure std:: HMAC-SHA256 keyed from PROVEN_SIGNING_KEY or key identity.

Attestations

in-toto v1 Provenance Envelopes

Generates verifiable in-toto Statement v1 JSON binding release binaries to exact cryptographic digests and Merkle roots.

Integrity

64 KiB Merkle Tree Root

Streams source and binary files in 64 KiB chunks to compute a deterministic SHA-256 Merkle root binding compiled artifacts to verified builds.

Offline

Air-Gappable & Zero Dependencies

Built purely in Rust standard library (std::). Validates provenance air-gapped without requiring calls to central transparency logs.

02 · GITHUB ACTIONS & CLI

GitHub Actions & CI enforcement.

Verify artifact byte-identity and attach HMAC-SHA256 in-toto attestations in CI.

# .github/workflows/proven.yml
name: proven
on:
  push: { branches: [ master, main ] }
  pull_request: { branches: [ master, main ] }
  workflow_dispatch:
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}
permissions: { contents: read }
jobs:
  proven:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
        with: { fetch-depth: 0 }
      - uses: studio2201/proven@v1
        with: { path: 'target/release/your-binary' }
      - uses: actions/upload-artifact@v6
        if: always()
        with: { name: proven-report, path: proven_summary.md, if-no-files-found: ignore }
# Workstation CLI installation:
cargo install --git https://github.com/studio2201/proven
PROVEN_SIGNING_KEY="your-secret" proven attest --target target/release/app --key release-key

Verification
