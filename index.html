Five products. Pure Rust. Apache-2.0.

v0.2.5

Vigil

Supply-chain dormancy scanner. Reads your manifest (package.json, Cargo.lock, pyproject.toml, …), scores each dependency by dormancy, emits SUPPLY-CHAIN.md and a badge.

Overview & Specs →
v0.2.5

Proven

PQC-signed supply-chain attestor. Reproducible builds with byte-identity hashing keyed on (host, rustc-version, Cargo.lock). Air-gappable, post-2030 valid.

Overview & Specs →
v0.2.5

Aegis

PQC migration SDK. Scans RSA/ECC usage, plans in OMB M-26-15 format, emits ML-KEM-768 / ML-DSA-65 replacements. Targets the Dec 31, 2030 federal deadline.

Overview & Specs →
v0.2.5

Snip

Vibe-code security gate. Audits AI-generated diffs for hardcoded credentials, missing CSP/CORS, and broken Supabase RLS. Ships as MCP server, GitHub Action, CLI, and Cursor skill pack.

Overview & Specs →
v0.2.5

Boneyard

Org-wide tech-debt radar. Ranks internal repos by dormancy, risk, exposure, dependency depth, and AI-agent surface. Emits remediation budgets in repo-weeks.

04

CI/CD & GitHub Actions Enforcement

Zero-dependency automated security gates on every pull request and push using the unified composite action.

# Prompt for your AI Agent (Cursor, Claude Code, Copilot, Devin):
Add a GitHub Actions workflow at .github/workflows/studio2201.yml using studio2201/studio2201@master. Configure it to trigger on pull requests and pushes to master, auditing PR diffs with Snip, dependencies with Vigil, and crypto with Aegis, outputting scorecards to $GITHUB_STEP_SUMMARY and failing on security violations.
# .github/workflows/studio2201.yml
name: studio2201 Security Gate
on: [pull_request, push]
jobs:
  security-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - name: Run studio2201 Multi-Tool Security Gate
        uses: studio2201/studio2201@master
        with:
          tools: 'all'
          fail-on: 'block'
# Workstation CLI installation (unprivileged, installs to ~/.local/bin):
curl -fsSL https://studio2201.com/install.sh | sh -s all
