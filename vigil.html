Vigil

Supply-chain dormancy scanner. Reads your project manifest, scores each dependency by how long it has been since the upstream moved, and emits SUPPLY-CHAIN.md and a badge.

View on GitHub → Framework Doctrine →

01

What it does

Auto-detect Manifests

Parses package.json, Cargo.lock, pyproject.toml, go.mod, pom.xml, composer.json, pubspec.yaml, and Package.swift.

Upstream Activity Heuristic

Cross-references dependencies against upstream commit velocity, release cadence, maintainer activity, and dormancy thresholds.

SUPPLY-CHAIN.md

Emits an actionable audit ranking packages from dormant risk to actively maintained, with remediation budgets in repo-weeks.

README Badge

Generates an SVG badge for your repository to display supply-chain health and attestation state in real-time.

02

GitHub Actions & CI Enforcement

Automate dependency dormancy checks on every pull request and push using the Vigil GitHub Action.

# Prompt for your AI Agent (Cursor, Claude Code, Copilot, Devin):
Add a GitHub Actions workflow at .github/workflows/vigil.yml using studio2201/vigil@master. Trigger on PRs and master pushes, scan dependency manifests for packages dormant over 180 days, write a dormancy scorecard to $GITHUB_STEP_SUMMARY, and fail the build if abandoned dependencies are detected.
# .github/workflows/vigil.yml
name: Vigil Supply-Chain Gate
on: [pull_request, push]
jobs:
  vigil-scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Audit Dependency Dormancy
        uses: studio2201/vigil@master
        with:
          path: '.'
          max-dormancy: '180'
# Workstation CLI installation (unprivileged, installs to ~/.local/bin):
curl -fsSL https://studio2201.com/install.sh | sh -s vigil

03

Terminal usage

# Scan current working directory manifest
vigil scan

# Emit structured JSON for CI ingestion
vigil scan --format json --output supply-chain.json

# Check policy against dormancy thresholds
vigil policy check --max-dormancy 180d

04

Why This Matters & Authoritative Mandates

Over 80% of application code comes from open-source libraries. Manual tracking cannot scale across hundreds of dependencies; automated CI gates halt pull requests before abandoned packages merge.

CISA OSS Security Roadmap ↗

Warns that unmaintained and abandoned dependencies are prime targets for maintainer account takeovers and malicious injection.

Harvard / LF Census III ↗

Finds that 96% of critical open source software applications rely on packages with fewer than 2 active maintainers.

OpenSSF Scorecards ↗

Identifies maintenance velocity and commit freshness as key indicators of open-source software security and health.

CVE-2024-3094 (XZ Utils) ↗

Demonstrates how social engineering over years targeted a single exhausted maintainer of a critical dormant library.

05

How It Works Under the Hood

Multi-Manifest Parsing

Scans project trees to locate lockfiles, extracting package names, versions, and repository coordinates with zero external crates.

Commit Velocity Scoring

Computes dormancy as days elapsed since the latest release or upstream commit, mapping scores to Red/Amber/Green tiers.

Native SVG Badge Emission

Generates standalone SVG badges directly in pure Rust without headless browser or image rendering dependencies.

Automated CI Gating

Fails builds with exit code 1 when dependencies exceed dormancy policies (e.g. --max-dormancy 180d).
