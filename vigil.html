VIGIL · v0.2.14 · APACHE-2.0 · PURE STD:: RUST

Vigil — supply-chain dormancy scanner.

Reads your project manifest, queries live registries, scores each dependency by how long it has been since the upstream moved, and emits SUPPLY-CHAIN.md and an SVG badge.

01 · CAPABILITIES

What it does across your dependency tree.

Manifests

Auto-Detect Manifests

Parses package.json, Cargo.lock, Cargo.toml, requirements.txt, and go.mod, and queries npm, crates.io, PyPI, and proxy.golang.org directly.

Signals

Upstream Activity Heuristic

Cross-references dependencies against upstream commit velocity, release cadence, maintainer activity, and dormancy thresholds.

Reporting

SUPPLY-CHAIN.md

Emits an actionable audit ranking packages from dormant risk to actively maintained, with remediation budgets in repo-weeks.

Visibility

README Badge

Generates an SVG badge for your repository to display supply-chain health and attestation state in real time.

02 · GITHUB ACTIONS & CLI

GitHub Actions & CI enforcement.

Automate dependency dormancy checks on every pull request and push using the standalone Vigil GitHub Action.

# .github/workflows/vigil.yml
name: vigil
on:
  push: { branches: [ master, main ] }
  pull_request: { branches: [ master, main ] }
  workflow_dispatch:
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}
permissions: { contents: read }
jobs:
  vigil:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
        with: { fetch-depth: 0 }
      - uses: studio2201/vigil@v1
      - uses: actions/upload-artifact@v6
        if: always()
        with: { name: vigil-report, path: vigil_summary.md, if-no-files-found: ignore }
# Workstation CLI installation:
cargo install --git https://github.com/studio2201/vigil
vigil scan && vigil policy check --max-dormancy 180d

04 · ARCHITECTURE

How it works under the hood.

Zero Crates

Multi-Manifest Parsing

Scans project trees to locate lockfiles, extracting package names, versions, and repository coordinates with zero external crates.

Live Registries

Commit Velocity Scoring

Computes dormancy as days elapsed since the latest release or upstream commit, mapping scores to Red/Amber/Green tiers.

Pure Rust

Native SVG Badge Emission

Generates standalone SVG badges directly in pure Rust without headless browser or image rendering dependencies.

Policy Gate

Automated CI Gating

Fails builds with exit code 1 when dependencies exceed dormancy policies (e.g. --max-dormancy 180d).
