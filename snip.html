02 · GITHUB ACTIONS & CLI

GitHub Actions & CI enforcement.

Block leaked API keys, missing RLS, and permissive CORS in pull request diffs before code merges.

# .github/workflows/snip.yml
name: snip
on:
  push: { branches: [ master, main ] }
  pull_request: { branches: [ master, main ] }
  workflow_dispatch:
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}
permissions: { contents: read }
jobs:
  snip:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
        with: { fetch-depth: 0 }
      - uses: studio2201/snip@v1
      - uses: actions/upload-artifact@v6
        if: always()
        with: { name: snip-report, path: snip_summary.md, if-no-files-found: ignore }
# Workstation CLI & MCP installation:
cargo install --git https://github.com/studio2201/snip
git diff --staged | snip audit && snip serve --mcp

04 · ARCHITECTURE

How it works under the hood.

Parser

Diff Addition Lexer

Evaluates only lines beginning with + to eliminate false positives in unchanged code and removed lines.

Heuristics

High-Confidence Patterns

Performance

Sub-Millisecond Execution

Zero external crates. Scans large 10,000-line diffs in <5 ms locally on developer laptops before commits stage.

Native stdio MCP Transport

Implements JSON-RPC 2.0 framing over standard I/O for instant integration into AI developer editors.
